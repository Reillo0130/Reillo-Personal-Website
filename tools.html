CAMERA CHECK / 03

相机快门数查询

选择相机直出的 JPEG 或 RAW 文件，尝试读取文件内记录的快门计数。

S
查看快门计数支持范围与品牌

当前版本识别 ExifTool 中有明确快门计数字段的常见品牌：

  • Canon — ShutterCount、ImageCount
  • Nikon — ShutterCount、MechanicalShutterCount、ImageCount
  • Sony — ShutterCount、ShutterCount2/3、ImageCount
  • Fujifilm — ImageCount、ExposureCount
  • Pentax — ShutterCount

这些是品牌级的字段范围，不代表该品牌每一款机型都会写入快门数。Olympus/OM System、Panasonic/Lumix、Leica、Ricoh 等相机的 EXIF 信息也可能被读取，但快门计数是否可用取决于机型、固件和文件内容。更多 MakerNotes 字段请查看 ExifTool 标签文档。

照片仅在本机解析，不会上传。只有使用此工具时才会从 CDN 加载约 8 MB 的 ExifTool 解析引擎；失败后可重新点击查询。

NETWORK CHECK / 04

公网 IPv4 查询

检测请求会发送到 ipify；该服务可看到请求的出口 IP。结果仅显示在本页，不由本站保存。

NETWORK CHECK / 05

IPv6 连通性查询

连接 IPv6 专用服务，检查当前网络是否能通过 IPv6 访问公网。

6

尚未检测

IPv6 检测请求会发送到 ipify IPv6 端点；服务方可看到出口地址。连接失败也可能由防火墙或服务限制导致。

NETWORK CHECK / 06

NAT 映射探测

比较不同 STUN 服务观察到的 WebRTC 公网映射。

N

尚未检测

Google 和 Cloudflare STUN 服务会收到探测包并可看到网络出口地址与端口。浏览器测试不能完成 RFC 5780 完整映射/过滤测试，因此只报告可观测特征，不判定 Full Cone、Restricted 或 Symmetric 等 NAT 类型。
